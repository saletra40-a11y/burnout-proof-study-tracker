# Burnout-Proof Study Tracker — public demo (Grad-IQ)

Live demo: https://gradiq.github.io/burnout-proof-study-tracker/

This is the **demo-only** edition. It runs on sample data, saves nothing, and has no export/import. The full tracker (saves in your browser, JSON backup/restore, CSV export, print) is sold separately as a download.

Sections: "minimum good day" standard + one-line daily log with streak and 7-day view · focus timer with session log · flashcard session log with next-review dates · weekly review · support contacts (988 and your own campus resources).

Static HTML/CSS/vanilla JS. Self-hosted fonts. No tracking, no outside requests. Shop link and price live in `config.js` (`BUY_URL`, `PRICE`).

A study-planning tool only. Not medical or mental-health advice, diagnosis or treatment. In the U.S., call or text 988 if you're in crisis.
